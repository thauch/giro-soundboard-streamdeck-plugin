# Changelog

## 0.6.7

- Shortened the success checkmark to a 250 ms flash so playback progress returns sooner.

## 0.6.6

- Added a progress bar to playing sound keys using native playback position and duration.
- Progress resets when a sound restarts, finishes, fails, or is stopped.

## 0.6.5

- Removed XL-specific plugin/download branding; the plugin works with Stream Deck keypad buttons across device models.
- Kept XL labels only for the optional profiles made for that device layout.

## 0.6.4

- Direct Discord sign-in and account favorites.
- Auto-filled favorite keys, pinned favorites, custom wrapping labels, and paging placeholders.
- Windows audio output selection and streaming without saving sound files.
- Persistent Windows player with fast restarts and no overlapping sounds.
- Local, Squad, and Off PTT modes; Local/K and Squad/J defaults.
- Held PTT repeats key-down without release pulses or menu-key hooks.
- Automated GitHub builds, installer bundles, and tagged releases.

Actual Stream Deck hardware, Windows audio, and Wardogs input behavior require verification on those systems.
